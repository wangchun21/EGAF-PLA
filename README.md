### EGAF-PLA
Mitigating Modality Collapse via Entropy-Regularized Gated Attention Fusion for Multimodal Protein–Ligand Binding Affinity Prediction

### Requirements
conda env create -f environment.yml -n EGAF-PLA

### Data
We use PDBBind v2020 as our dataset, the official original dataset can be downloaded from https://www.pdbbind-plus.org.cn/.

### Pre_data
We provide input files in the `pre_data/` directory to reproduce the data in the paper.

### Training
Run train.py for training.

### Results
Prediction results are saved in the `results/` directory.
